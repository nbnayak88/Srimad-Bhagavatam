# Bhagavad-gītā As It Is — Study Repository

Organized study folders for the four introductory sections and 18 chapters, with references to Śrīla Prabhupāda's Bhagavad-gītā As It Is on Vedabase.

**Primary text:** [Vedabase — Bhagavad-gītā As It Is](https://vedabase.io/en/library/bg/)

Each numbered folder contains a chapter or introductory-section README for future study notes, verse references, and assessments.
